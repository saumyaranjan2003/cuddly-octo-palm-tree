# Kanban Board
A simple Kanban board web app using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Add, move, and delete tasks
- Columns: To Do, In Progress, Done
- Responsive and modern UI (Bootstrap)
- No backend required

## Usage
Open `index.html` in your browser.

## Customization
- Edit the HTML to add more columns or change column names.
- Style with Bootstrap or custom CSS in `styles.css`.
